Overview

This vignette translates the mixOmics N-Integration Chapter 6 case study into the stablr idiom. The original mixOmics workflow uses sparse multi-block Discriminant Analysis (sgccaDA) to classify breast cancer subtypes. Here we ask the same scientific question — which mRNA and miRNA features robustly distinguish Basal-like tumours from all other subtypes? — using STABL’s bootstrap stability approach.

Dataset: breast.TCGA from the mixOmics package.

  • Training: 150 samples x 520 mRNA features + 150 samples x 184 miRNA features.
  • Test: 70 samples x same features.
  • Outcome: five PAM50 subtypes, binarised to Basal vs. non-Basal.
  • Protein data (142 features) is excluded, matching the two-omic scope of Chapter 6.

What you will learn:

  1. How to load and prepare breast.TCGA for stablr.
  2. How to run per-omic STABL as a baseline.
  3. How to run the integrated multi-omic pipeline (early + late fusion).
  4. How to evaluate validation performance with confusion matrices and BER.
  5. How to export results for downstream reporting.

2. Per-omic STABL

We assess each omic independently before running integration. n_bootstraps = 50 is used here for a vignette-friendly runtime; increase to 500-1000 for publication results.

2a. mRNA

lambda_mrna <- auto_lambda_grid(
  X_train_mrna, y_train,
  family   = "binomial",
  n_lambda = 20
)
fit_mrna <- stabl_fit(
  x               = X_train_mrna,
  y               = y_train,
  lambda_grid     = lambda_mrna,
  family          = "binomial",
  n_bootstraps    = 50L,
  artificial_type = "random_permutation",
  random_state    = 42L
)

  y_valid         = y_test,

pred_class <- as.integer(lf_preds >= 0.5)

#>          Actual
#> Predicted  0  1

#>         1  3 18

sensitivity <- conf_mat["1", "1"] / sum(conf_mat[, "1"])
specificity <- conf_mat["0", "0"] / sum(conf_mat[, "0"])
ber <- 1 - (sensitivity + specificity) / 2

7. Comparison with mixOmics

Aspect mixOmics (sgccaDA) stablr
Method Sparse CCA + LDA Bootstrap-stability LASSO
Feature selection L1 penalty tuned by CV FDP-controlled stability threshold
Integration Joint latent-space optimisation Early or late fusion
Primary metric BER on test set FDP+ stability score
Output Components + loadings Feature names + stability scores

Both approaches identify a compact, reliable set of mRNA and miRNA biomarkers for the Basal subtype. STABL’s advantage is explicit FDP control with no assumption of a shared latent space between omics.
